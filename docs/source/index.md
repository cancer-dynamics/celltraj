# celltraj documentation

`celltraj` is a Python toolkit for single-cell trajectory modeling, live-cell
feature analysis, trajectory embedding, and dynamical modeling.

```{note}
The documentation has been moved to the same source/build/publish pattern used
by `sitelab`. The public docs are generated from this repo but published
through CancerDynamics.org.
```
