# Tutorials

The repository includes tutorial notebooks under `tutorials/`:

- `trajectory_embedding.ipynb`
- `mmist.ipynb`

These notebooks are valuable scientific examples, but some paths and links
still reflect older local-development conventions. As `celltraj` is integrated
with `sitelab`, the notebooks should be updated to import from the installed
package namespace instead of manually editing `sys.path`.

Current documentation URL:

```text
https://cancerdynamics.org/docs/celltraj/
```
